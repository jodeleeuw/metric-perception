How it plugs in

Both modules are now wired into the experiment. Dancers are posed from the same fractional beat time the plugin already computes each frame. The rhythm is a per-phase pattern from config.js, scheduled by rhythm.js on the audio clock, with every hit logged in the trial data.

// What plugin-metrical-trajectory.js now does, trimmed to the essentials.
const left  = new Dancer({ meter: 2, ...CONFIG.CHARACTERS.left,  motion: CONFIG.DANCER_MOTION });
const right = new Dancer({ meter: 3, ...CONFIG.CHARACTERS.right, motion: CONFIG.DANCER_MOTION });

const player = new Rhythm.Player(audioContext, masterGain, { voiceGain: CONFIG.VOICE_GAINS });
const sequencer = new Rhythm.Sequencer(player, {
  startTime, period,
  patternAt: (beat) => beat >= cueStart ? patterns[cuedMeter] : patterns.ambiguous,  // phase -> pattern
  endBeat: totalBeats,
});
setInterval(() => onsets.push(...sequencer.schedule(audioContext.currentTime + 0.1)), 25);

function frame() {
  const tBeats = (audioNow() - startTime) / period;
  left.update(tBeats);
  right.update(tBeats);
  requestAnimationFrame(frame);
}

Things to decide

  • Salience. Strong beats now carry three signals (big bob, knee dip, foot tap). The circles only changed size. If gaze during the ambiguous phase parks on whichever dancer moves more, tune the motion sliders until the two look equally busy per 6-beat window, or move the tap to every beat and keep only the bob difference.
  • Tap timing. The toe rises over the half beat before a strong beat and lands at the beat onset. That anticipation is what makes it read as dancing rather than reacting, but it also previews the strong beat visually. Say if you would rather it landed cold.
  • Rendering. The plugin draws on a canvas. Dancers are SVG DOM elements, so they would sit in absolutely positioned divs over (or instead of) the canvas. The clock and beat logic do not change.
  • Generator scope. The rhythm generator is for exploring how the dancers read against richer stimuli. The plugin keeps its own single-tone scheduler; if a preset here turns out to be a better cue than the +6 dB accent, the voice synths port over as-is since they use the same clock and lookahead.
  • Identity. Randomizing which character goes on which side per trial is free. Keeping two fixed characters for the whole session is also free. Either way the dance is identical across characters; only the meter differs.
